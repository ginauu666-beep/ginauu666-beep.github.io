Social Media Dashboard

A desktop dashboard for reviewing data from social media accounts that you connect. It brings account metrics, video performance, and available interaction records into one workspace.

社媒数据看板在用户电脑上运行，用于汇总已授权账号的数据、作品表现和可获取的互动记录。

How account connections work

You choose which accounts to connect through each platform's authorization flow. The dashboard requests only the permissions shown on that platform's consent screen. Features that need additional permissions remain unavailable until you separately authorize them.

Platform credentials and collected dashboard data are stored on the computer running the application. The application communicates with platform APIs to retrieve authorized data and, when you explicitly initiate an available action, to submit it.

Current integrations

  • YouTubeChannel and video data, analytics, and user-initiated comment publishing after the required permission is granted.
  • TikTokSandbox Login Kit and authorized profile and public video data. Comment, like, and direct-message publishing are not available in this integration.

Other platforms may be supported through separate account connections. Available data depends on each platform's permissions and interfaces.

Policies and contact

Read the Privacy Policy and Terms of Service before connecting an account. For questions about this project, use the project's GitHub issues page. Do not post passwords, tokens, or private account data in a public issue.
